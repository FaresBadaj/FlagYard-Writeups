PART 2 - KEY GENERATION MATH (from server.py)
====================================================================
- RSA 2048. p,q 1024-bit primes. N = p*q, e = 16-bit prime (42239).
- dp = e^{-1} mod (p-1)  =>  e*dp = 1 + k*(p-1),   1<=k<=e-1  =>  k*p = e*dp + k - 1
- dq = e^{-1} mod (q-1)  =>  e*dq = 1 + l*(q-1),   1<=l<=e-1  =>  l*q = e*dq + l - 1
- Given: dp % 2^512 and dq % 2^512 only.

p = (e*dp + k - 1)/k ,  q = (e*dq + l - 1)/l ,  p*q = N
=> (e*dp + k - 1)(e*dq + l - 1) = k*l*N        ... (*)

Taking (*) mod MOD=2^512 with dp_low,dq_low:
    A  = e*(dp_low + dq_low) - e^2*dp_low*dq_low - 1
    f(x,y) = (N-1)*x*y - (e*dq_low-1)*x - (e*dp_low-1)*y + A
True (k,l) satisfies f(k,l) ≡ 0 (mod e*MOD).
